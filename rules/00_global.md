# 全局规则

> 适用于所有项目的基础规则

---

## 语言

所有交互用**中文**

## 项目启动

所有项目由我自己启动，不要擅自启动，除非采用狂暴模式“bypass permissions on”

## 问题处理

遇到问题先查询 `docs/fixed/` 下的错误记录

## 响应格式

- 简洁直接，不废话
- 代码优先，能用代码表达的不用文字
- 代码变更后简要说明改了什么

## 退出前文档同步 🔴

退出 Claude Code 前（用户说 exit、结束对话），**必须**将本次会话的所有变更同步到以下文档的对应位置：

1. **README.md** — 目录结构、功能表、版本号
2. **docs/GUIDE.md** — 配置说明、使用方法、流程图

**检查清单**：
- 新增/删除了文件或目录？→ 同步目录结构
- 新增/修改了 Skill？→ 同步技能总览表
- 新增/修改了 Agent 角色？→ 同步角色表
- 修改了配置文件？→ 同步配置说明
- 修改了工作流？→ 同步流程图
- 版本号变更？→ 同步版本号

**未完成同步前，不得退出。**
