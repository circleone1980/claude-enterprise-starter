## 二、系统架构图

### 2.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      用户界面层 (Frontend)                   │
│  [React + TypeScript + Tailwind CSS + Zustand]             │
└─────────────────────────────────────────────────────────────┘
                              ▲
                              │ HTTPS / WebSocket
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                      API 网关层 (API Gateway)                │
│  [Nginx / Kong / AWS API Gateway]                          │
└─────────────────────────────────────────────────────────────┘
                              ▲
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
        ▼                     ▼                     ▼
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  认证服务    │    │  业务服务    │    │  文件服务    │
│  (Auth)      │    │  (Business)  │    │  (File)      │
└──────────────┘    └──────────────┘    └──────────────┘
        │                     │                     │
        └─────────────────────┼─────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                      数据层 (Data Layer)                     │
│  [PostgreSQL + Prisma ORM + Redis Cache]                   │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 组件说明

| 组件 | 技术栈 | 职责 |
|------|--------|------|
| **Frontend** | React + TypeScript | 用户界面、交互逻辑 |
| **API Gateway** | Nginx | 负载均衡、路由、限流 |
| **Auth Service** | FastAPI | 认证、授权、Token 管理 |
| **Business Service** | FastAPI | 核心业务逻辑 |
| **File Service** | FastAPI + S3 | 文件上传、存储、处理 |
| **Database** | PostgreSQL | 持久化数据存储 |
| **Cache** | Redis | 会话、热点数据缓存 |

## 四、数据流设计

### 4.1 用户认证流程
```
用户 → 前端 → API Gateway → Auth Service
                                  ↓
                            验证凭证
                                  ↓
                            生成 JWT
                                  ↓
                            缓存到 Redis
                                  ↓
                         返回 Token 给前端
```

### 4.2 业务数据流
```
用户操作 → 前端 → API → Business Service
                                ↓
                          业务逻辑处理
                                ↓
                          数据验证
                                ↓
                          写入数据库
                                ↓
                          更新缓存
                                ↓
                         返回响应给前端
```

## 七、安全设计

### 7.1 认证与授权
- **认证方式**: JWT (Access Token + Refresh Token)
- **授权机制**: RBAC (基于角色的访问控制)
- **Token 有效期**: Access Token 15 分钟, Refresh Token 7 天

### 7.2 数据安全
- **传输加密**: HTTPS (TLS 1.3)
- **存储加密**: AES-256 (敏感数据)
- **密码存储**: bcrypt (salt rounds = 12)

### 7.3 防护措施
- **SQL 注入**: Prisma ORM 参数化查询
- **XSS**: React 自动转义 + CSP
- **CSRF**: SameSite Cookie + CSRF Token
- **Rate Limiting**: API Gateway 限流
