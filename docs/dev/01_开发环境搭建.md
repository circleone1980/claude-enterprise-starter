## 前置要求

- Node.js 20.x
- Python 3.11+
- PostgreSQL 15
- Redis 7

## 快速开始

```bash
# 1. 克隆项目
git clone https://github.com/org/project.git
cd project

# 2. 安装前端依赖
cd frontend && npm install

# 3. 安装后端依赖
cd ../backend && pip install -r requirements.txt

# 4. 启动数据库
docker-compose up -d postgres redis

# 5. 运行迁移
python scripts/migrate.py

# 6. 启动开发服务器
npm run dev
```
