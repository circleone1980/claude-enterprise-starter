## 一、设计原则

### 1.1 核心原则
- **一致性**: 统一的视觉语言和交互模式
- **简洁性**: 减少视觉噪音，突出核心内容
- **可用性**: 符合用户心智模型，降低学习成本
- **响应式**: 适配多种设备和屏幕尺寸

### 1.2 设计系统
- **组件库**: shadcn/ui
- **图标库**: Lucide React
- **设计工具**: Figma
- **样式方案**: Tailwind CSS

## 五、组件规范

### 5.1 按钮

**主按钮（Primary）**:
```tsx
<Button variant="primary" size="md">
  主要操作
</Button>
```

**尺寸**:
- `sm`: 高度 32px, padding 8px 16px
- `md`: 高度 40px, padding 12px 24px
- `lg`: 高度 48px, padding 16px 32px

### 5.2 输入框

**文本输入框**:
```tsx
<Input 
  type="text" 
  placeholder="请输入内容" 
  error={errorMessage}
/>
```

**高度**: 40px (与按钮对齐)

### 5.3 卡片

**基础卡片**:
```tsx
<Card>
  <CardHeader>
    <CardTitle>卡片标题</CardTitle>
  </CardHeader>
  <CardContent>
    卡片内容
  </CardContent>
</Card>
```

**圆角**: 8px
**阴影**: `shadow-sm`

## 七、交互规范

### 7.1 加载状态
- **骨架屏**: 首次加载内容时
- **按钮加载**: 提交表单时按钮显示 loading 图标
- **页面加载**: 全局 loading 指示器

### 7.2 空状态
- 显示友好的空状态插图
- 提供明确的引导操作

### 7.3 错误提示
- **Toast**: 轻量级错误提示
- **Alert**: 重要错误提示
- **Inline**: 表单字段错误提示

---

## 八、无障碍规范

- **对比度**: 文本对比度 ≥ 4.5:1
- **焦点可见**: 所有交互元素支持键盘导航
- **屏幕阅读器**: 提供正确的 aria 标签
- **动效**: 支持减少动效设置
