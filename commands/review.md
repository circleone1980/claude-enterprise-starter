# 代码审查

## 功能

对代码进行全面审查，检查代码质量、安全性、性能和最佳实践。

## 审查维度

### 1. 代码质量

- [ ] 代码是否清晰易读
- [ ] 命名是否有意义
- [ ] 是否有重复代码
- [ ] 函数是否过长
- [ ] 注释是否充分

### 2. 安全性

- [ ] 是否有 SQL 注入风险
- [ ] 是否有 XSS 漏洞
- [ ] 敏感数据是否正确处理
- [ ] 权限检查是否完善

### 3. 性能

- [ ] 是否有不必要的循环
- [ ] 数据库查询是否优化
- [ ] 是否有内存泄漏风险
- [ ] 缓存使用是否合理

### 4. 最佳实践

- [ ] 是否遵循项目规范
- [ ] 错误处理是否完善
- [ ] 日志记录是否合理
- [ ] 测试覆盖是否充分

## 审查报告格式

```markdown
# 代码审查报告

## 概述
[简要描述审查结果]

## 发现的问题

### 🔴 严重
- [问题描述]
  - 位置: file:line
  - 建议: [修复建议]

### 🟡 中等
- [问题描述]

### 🟢 轻微
- [问题描述]

## 优点
- [代码亮点]

## 建议
- [改进建议]
```

## 使用方式

```
/review              # 审查当前分支的所有变更
/review src/         # 审查指定目录
/review src/auth.ts  # 审查指定文件
```
